# Evolution of Communication — Node.js Exhibition

A highly visual bilingual exhibition website built with Node.js + Express.

## Run locally

```bash
npm install
npm start
```

Open **http://localhost:3000**.

## Features

- Five immersive communication eras
- English / Sinhala language switch
- Animated hero signal journey
- Visual artifact walls and technology diagrams
- Morse + binary text converter
- Interactive knowledge quiz
- Fully responsive exhibition layout
